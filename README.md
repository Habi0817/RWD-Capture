# RWD Capture

**Chrome／Edge 雙瀏覽器 RWD 網頁自動截圖工具**

以 Vue 3、TypeScript、Node.js 與 Playwright 製作的 Windows 本機工具。輸入網址、選擇尺寸，即可批次擷取全頁 PNG，並在圖庫中並排查看 Chrome 與 Edge 的呈現結果。

## 功能特色

- 使用本機安裝的 Google Chrome、Microsoft Edge。
- 預設 12 組 RWD 尺寸，雙瀏覽器共產生 **24 張截圖／網址**。
- 依裝置設定切換桌面／行動 UA、觸控與裝置像素倍率。
- 擷取前自動捲動，觸發延遲載入，等待圖片解碼與字型載入。
- 公開頁面可直接截圖；會員頁面可手動登入並保存各瀏覽器的狀態。
- 提供執行進度、取消、未完成項目重試、歷史紀錄與放大預覽。
- 本機保存截圖與執行報告，也可匯出至指定資料夾。
- JSON 設定可編輯、匯入與匯出。

## 快速開始

### 環境需求

- Windows 10／11
- Node.js 22 LTS（建議使用 22.12 以上）
- Google Chrome、Microsoft Edge
- 首次安裝套件時需要網際網路

### 下載與啟動

下載本儲存庫 ZIP 並解壓，進入內層 **`RWD-Capture`** 資料夾，雙擊 **`start.cmd`**。

或使用 Git：

```powershell
git clone https://github.com/Habi0817/RWD-Capture.git
cd RWD-Capture\RWD-Capture
.\start.cmd
```

啟動腳本會在缺少相依套件時執行 `npm ci`，接著建置並啟動服務，自動開啟：

**http://127.0.0.1:4317**

請保持命令視窗開啟；按 `Ctrl+C` 停止服務。這是需要本機 Node.js 服務的工具，無法只靠 GitHub Pages 執行。

## 使用方式

### 不需要登入的頁面

1. 輸入完整的 `http://` 或 `https://` 網址。
2. 勾選 Chrome／Edge 與所需尺寸。
3. 保持「使用已保存的登入狀態」未勾選。
4. 按「開始擷取」，等待結果出現在圖庫。

### 需要登入的頁面

1. 輸入網站網址，勾選「使用已保存的登入狀態」。
2. 按 Chrome 的「開啟登入」，在專用視窗內手動完成登入。
3. 回到工具按「完成登入並保存」。
4. 若也要擷取 Edge，對 Edge 重複上述步驟。
5. 選擇尺寸並開始擷取；本次選取的每個瀏覽器都需有已保存狀態。

登入狀態分瀏覽器保存，不會讀取日常使用的 Chrome／Edge 個人資料。可按「清除」移除工具保存的狀態；若截到登入畫面，請重新登入並保存。

### 查看與匯出

- 依尺寸並排查看兩個瀏覽器，點擊圖片放大或開啟原圖。
- 「開啟輸出資料夾」可查看 PNG 與 `manifest.json`。
- 工作結束後，輸入完整本機路徑（例如 `D:\Screenshots`），即可匯出本批截圖與報告。
- 每批使用獨立工作資料夾，避免覆寫既有結果。

## 預設尺寸

以下寬高為 **CSS viewport**，不是 PNG 的最終像素尺寸。

| 類型 | 寬 × 高 | 裝置倍率 |
| --- | --- | --- |
| 桌面 | 2500 × 1080 | 1× |
| 桌面 | 1440 × 768 | 1× |
| 平板 | 1024 × 1366 | 2× |
| 平板 | 1023 × 1366 | 2× |
| 平板 | 768 × 1024 | 2× |
| 平板 | 767 × 1024 | 2× |
| 行動 | 650 × 932 | 3× |
| 行動 | 550 × 932 | 3× |
| 行動 | 450 × 932 | 3× |
| 行動 | 375 × 667 | 2× |
| 行動 | 374 × 667 | 2× |
| 行動 | 320 × 800 | 3× |

例如 viewport 寬度 375、倍率 2，PNG 寬度為 **750 像素**。預設擷取整個可捲動頁面，因此輸出高度依頁面內容而定。
